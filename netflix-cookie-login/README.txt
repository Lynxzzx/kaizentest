╔══════════════════════════════════════════════════════════╗
║          NETFLIX COOKIE LOGIN - Extensão de Navegador    ║
╚══════════════════════════════════════════════════════════╝

Compatível com: Chrome, Edge, Opera, Brave, Firefox

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  INSTALAÇÃO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ Chrome / Edge / Opera / Brave ]
  1. Abra: chrome://extensions  (ou edge://extensions)
  2. Ative "Modo do desenvolvedor" (canto superior direito)
  3. Clique em "Carregar sem compactação"
  4. Selecione a pasta "netflix-cookie-login"
  5. O ícone aparecerá na barra de ferramentas

[ Firefox ]
  1. Abra: about:debugging
  2. Clique em "Este Firefox"
  3. Clique em "Carregar complemento temporário"
  4. Selecione o arquivo "manifest.json" dentro da pasta
  Obs: Para uso permanente no Firefox, instale via about:addons

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  COMO USAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Clique no ícone "N" vermelho na barra de ferramentas
  2. Cole os cookies no formato Netscape (colunas com TAB):

     Exemplo:
     .netflix.com[TAB]TRUE[TAB]/[TAB]TRUE[TAB]1793639790[TAB]NetflixId[TAB]ct%3D...
     .netflix.com[TAB]TRUE[TAB]/[TAB]TRUE[TAB]1793639790[TAB]SecureNetflixId[TAB]v%3D3...

  3. Clique em "Fazer Login na Netflix"
  4. O navegador abrirá netflix.com/browse com a sessão ativa

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  COOKIES NECESSÁRIOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Os mais importantes para autenticação são:
  • NetflixId       — cookie de sessão principal
  • SecureNetflixId — cookie de sessão segura
  
  Você pode colar todos os cookies exportados; a extensão
  processará apenas os válidos (formato correto).

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ONDE OBTER OS COOKIES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Use extensões como:
  • Cookie-Editor    (Chrome/Firefox)
  • EditThisCookie   (Chrome)
  • cookies.txt      (Firefox)
  
  Exporte no formato "Netscape" e cole na extensão.
